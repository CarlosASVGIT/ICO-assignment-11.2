Descripción de la solución
La base de datos diseñada para el Mizrah Luxury Resort presenta soluciones para los anteriores problemas. Las reservaciones se gestionaron de tal forma que es posible incluir múltiples habitaciones en una sola reservación. Cada reservación está ligada a múltiples entidades detalle reservación que permiten mayor versatilidad para el manejo de reservaciones. La información del cliente también estará ligada a sus reservaciones y podrá incluir información de acompañantes de ser necesario. 
Los clientes tendrán la posibilidad de aprovechar paquetes promocionales que se les ofrezcan de acuerdo a los diferentes eventos que se realizarán en cada época del año. Las promociones tendrán estipulada una fecha de inicio y terminación, estarán ligadas a un evento específico y tendrán efecto en el precio total final del costo del servicio.
Para la implementación se recomienda el uso de MySQL como motor de base de datos. Este ha sido probado en entornos de similar escala y adicionalmente provee de un soporte robusto para triggers y procedimientos almacenados. También se recomienda implementar una base de datos centralizada en los servidores locales para permitir al Mizrah Luxury Resort gestionar sus operaciones y tener soporte para el futuro crecimiento del resort. El sistema operativo que se requiere es Ubuntu Server 22.04 LTS, basado en Linux, sin costo de licencia, estable y comúnmente usado para el gestionamiento de redes, infraestructuras, sitios web y servicios en la nube. Para el respaldo de datos se sugiere el uso de un NAS(Network Attached Storage) o en su defecto hacer respaldos en la nube(Google Drive u otros).
